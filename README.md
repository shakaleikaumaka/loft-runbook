# The Loft A/V Runbook 🌺

**Live dashboard:** https://loftrunbook-c4bdy2rg74-nqfhvcnv.taur.link/

The self-host guide for The Loft's audio/visual system at **Edge Esmeralda 2026** — written so *any resident* can power it up, run an event, and shut it down safely.

> **One page. One QR on the door. Anyone can run the room.**
> Open source the knowledge, not just the music.

## What's inside

- `index.html` — the whole runbook, self-contained: signal chains, power ON/OFF order, Yamaha MG12XU channel map, video & recording rig, battery plan, quick troubleshooting, a "Run This Runbook With an Agent" section (omni-model: paste the soul + this page into Taurus, Claude, ChatGPT, self-host, or any chat), and a "Fork This For Your Venue" section.

## Fork it 🍴

Everything here is **copyleft** — public domain, no permission needed. Fork it like crazy: map your own signal chain, write your own power sequence, put a QR on your door. The knowledge stops living in one tired human's head.

The big sibling playbook (with the AI assistant agent + jam protocol) lives at [opensourcestage](https://github.com/shakaleikaumaka/opensourcestage).

## Note on the music trail

The live taur.link dashboard carries Shaka's floating music player (injected at sync time, single line before `</body>`). The repo stays clean on purpose — a forked runbook shouldn't inherit the bard's soundtrack. 🎵
