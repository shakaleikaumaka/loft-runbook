The Loft A/V Runbook

The self-host guide for The Loft's audio/visual system — written so any resident can power it up, run an event, and shut it down safely.

One page. One QR on the door. Anyone can run the room.

🧠 The System at a Glance

The Yamaha MG12XU is the brain. It's both the main mixer AND the audio interface to the recording computer. Everything audio flows through it.

Signal chain — audio

Mics / inputs → Yamaha MG12XU mixer → (2× XLR out) → QSC Subwoofer → QSC 15" powered speakers (L + R + extra R at back)

Signal chain — recording

MG12XU → USB-C dongle → Computer (StreamYard) Sony ZV-10 camera → HDMI mini→HDMI → capture card → Computer Podium HDMI → converter → HDMI splitter → Projector → 2nd capture card → Computer

⚡ Power ON — Do This In Order

⚠️ Order matters. Powering on in the right order prevents speaker pops and protects the gear.
  1. Surge protector first. Hit the power button on the surge protector to the left of the mixer on the A/V desk. This powers the mixer and everything on the table with one button.
  2. Then each speaker + sub individually using the power button on the back of: QSC Subwoofer → QSC 15" Left → QSC 15" Right → QSC 15" extra Right (back of room). Speakers come on AFTER the mixer is already running.

📹 Video & Recording

  • Projector: ViewSonic Luminos Premium
  • Slides: podium HDMI + converter → HDMI splitter → (a) projector and (b) capture card on the desk
  • Camera: Sony ZV-10 → HDMI mini→HDMI → capture card → computer
  • Recording (StreamYard): audio from MG12XU via USB-C dongle · Video 1 = ZV-10 room camera · Video 2 = splitter feed (speaker slides)

🔋 Batteries

  • Mics use rechargeable batteries
  • Each night: remove batteries from mics, leave them charging in the wall charger
  • Before an event: reinsert charged batteries

🔌 Power OFF — Reverse Order

⚠️ Always power off speakers FIRST to prevent a loud pop.
  1. Power off all speakers + sub first (the QSC units, via back power buttons)
  2. THEN power off the mixer / A/V table (the surge protector)

Exactly the opposite of the power-on sequence.

🚨 Quick Troubleshooting

No sound from speakers?
  1. Is the surge protector / mixer powered on?
  2. Are the speakers + sub individually powered on (back buttons)?
  3. Channel fader up + main mix fader up on the MG12XU?
  4. Mic on + battery charged?
  5. Check XLR cables: mixer → sub → speakers
Mic not working?
  1. Battery charged + inserted?
  2. Mic powered on?
  3. Correct receiver on + channel fader up?
  4. Remember: Mic 1 & 2 share a receiver
No projector image?
  1. HDMI plugged in at podium + converter seated?
  2. HDMI splitter powered/connected?
  3. Projector on + correct input source?
Recording has no audio?
  1. USB-C dongle connected from mixer to computer?
  2. StreamYard audio source set to MG12XU?
